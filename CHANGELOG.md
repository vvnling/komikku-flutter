# Changelog

## 0.1.0 (2026-08-19)

Initial release — Komikku, rewritten in Flutter.

- Custom COMICKO design system (no Material/Cupertino): 8 palettes, panel
  frames, halftones, speed lines, fragment shaders, Rive state machines
- Library: categories (+ hidden), sorting, filtering, bulk actions, merge,
  continue reading, advanced search
- Browse: MangaDex source, local storage (folders/CBZ/ZIP), offline demo
  source with procedurally generated covers and pages, feed, saved searches
- Reader: paged LTR/RTL, webtoon and continuous viewers, spring transitions,
  pinch/double-tap zoom, autoscroll, scrubber, smart background, chapter
  edge swipes
- Downloads: queue with progress and cancellation, offline reading
- Updates: scheduled library checks, grouped updates tab
- Trackers: AniList (pin flow) + offline local tracking
- Backup/restore: JSON with library, categories, history, tracks, settings
- Migration between sources
- CI/CD: analyze+tests on push; tagged releases build Android/Web/Linux/
  Windows artifacts and publish GitHub Releases
